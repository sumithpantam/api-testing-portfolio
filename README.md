# API Testing Portfolio

**A practical portfolio of REST API test design, validation, and automation examples.**

This repository demonstrates how I approach API quality through clear test scenarios, response validation, environment and test data considerations, regression thinking, and beginner-level security checks.

## About me

I am a software tester with **4+ years of software testing experience**. My experience includes JavaScript-based API automation using **Apidog**, REST API testing, positive and negative scenarios, HTTP status and response validation, JSON/schema validation, environment and test data management, and regression testing. I am currently building my understanding of API security and OWASP guidance.

This is a documentation-led portfolio. The JavaScript sample is illustrative and is not configured to run against a live API. Examples describe test intent; they do not claim that a production system or security assessment was tested.

## What this portfolio shows

- Positive, negative, boundary, and security-focused test design
- HTTP status, headers, response body, and JSON structure validation
- Practical test strategy and regression considerations
- A JavaScript example using familiar assertion patterns
- Security learning scenarios grounded in safe, authorized testing
